# Manual validation before a live presentation

Automated coverage lives in `Tests` and `scripts/test-review-regressions.py`. These checks exercise real macOS interactions and hardware that the unit suite cannot replace.

- Switch Old Testament / New Testament with the pinned sidebar control, then scroll the books. Both full titles must fit at the narrowest sidebar width, and the switch must stay visible. Switching testaments must preserve the prepared passage and live output. Open references and saved entries from the opposite testament and confirm their books become visible and selected. Check that each passage tab retains its own filter and that Tab/Shift-Tab and VoiceOver can reach the switch and book list.
- Open John 3, Psalm 23, and Romans 8 in native tabs. Test Command-T, Command-W, Command-Shift-W, Command-Return, Control-Tab/Control-Shift-Tab, and Command-Shift-[/]. Drag to reorder, detach a tab, merge windows, and use Show All Tabs. Confirm each tab retains its own book/chapter/verse selection, unsubmitted draft, search mode/results/selection, insertion point, and scroll positions in the verse and saved panes.
- Project from one tab and prepare another via Open in New Tab on books, chapter buttons, verse/search rows, bookmarks, and history entries. Live output must stay unchanged. Switch tabs, then close the originating tab and even the last passage tab; output must continue. Reopen from the Dock and verify Preview, Blank, and Stop still control that same output. Check bookmark Undo/Redo across tabs and after closing the tab that made the edit.
- Start a slow reference submission or search-result projection in one tab, then project or Stop/Escape from another. Old work must not replace or reopen output. Changing another tab's translations must not cancel that pending request. Change translations in the source tab while another tab prepares output; the newer projection must still win.
- Project John 3:16 from Tab A, then change Primary and Secondary (including None) in Tab B. Only Tab B's rows, search results, pickers, and heading may change. Change translations in Tab A and check that live John 3:16 updates while both tabs keep their drafts and browsing. Repeat while blanked and while browsing elsewhere in Tab A. Close Tab A during a live translation refresh; it may finish, and subsequent changes elsewhere must leave that output unchanged.
- Check passage/translation headings, including empty tabs, search results, and Secondary set to None. The Secondary picker must stay visible, and choosing a translation must restore both texts. New tabs must copy the opening tab's choices once and then change independently. After changing translations, close all tabs or relaunch: the first passage must restore the last selection, including None. Settings must contain only Display and Bible Library, with import/removal available and no translation selectors.
- Start a text search from a loaded chapter and trigger a database search failure. While chapter rows remain visible, the tab heading and tooltip must stay on that passage. A successful retry should change both to Search. Confirm Help explains per-tab translations and Space, and Command-N copies the selected tab's choices.
- In light and dark appearance, check that only the source tab has a green dot and Live label, even when another tab is selected. Blank changes it to a muted Blanked marker; Stop removes it. Projecting from another tab transfers the marker only after success. Confirm status and full translation names are available in tooltips and VoiceOver, and check long headings in narrow, reordered, detached, and merged tabs.
- Load John 3, press Option-Down, then project verse 2. Confirm the rows, bookmark reference, live title, and projected text are all John 4. Repeat rapidly and across a book change. After John 3, select Romans and click chapter number 3; also activate it with Return.
- With a verse selected, use Up/Down, Option-Up/Down, and Space. The selected verse and current chapter must stay highlighted, including after projection stops and when focus moves to search. Browsing another chapter must highlight its selected verse while Live continues to show the projected reference. Change books at the same chapter/verse numbers and confirm row text updates too.
- In the native chapter grid, use all four arrow keys and confirm spatial navigation and focus stay there as chapters load. Resize the pane and confirm the number of columns adapts; chapter labels must be numbers only. Use Command-Left/Right to leave the grid. In the native verse list, check key repeat, Command-Up/Down, Page Up/Down, Home/End, Return, and an already-selected row click. Use Left/Right to move between columns, and Command-L to return to search. Open a translation picker and confirm background updates do not take its focus.
- While submitting references and loading chapters, confirm the status row and verse list stay in place. Loading uses a static label in reserved space beside Preview, Blank, and Stop.
- Scroll away from the selected verse and add/remove a bookmark from another row; the viewport must stay put. Submit the selected reference again and confirm it scrolls into view. Check both translation copy actions, native row context menus, and VoiceOver's Project verse/Open chapter actions.
- Navigate to Psalm 117:2, then activate Esther 8:9 from History. The verse must be centered when it fits; a verse taller than the viewport must start at the top. Repeat with the same History entry, a narrow window, large row text, and Secondary set to None. Resize the verse pane with Malayalam/English translations, scroll to the end of Esther 8:9, and verify complete wrapping without overlapping rows. Check accent highlights in both light and dark appearance.
- Project John 3:16, browse Romans 8, and leave an unsubmitted draft in search. Change either translation, including Secondary to None. The live reference must stay John 3:16. Repeat starting with a search-result projection.
- With NIV primary and NLT secondary, navigate to 3 John 1:15 or Revelation 12:18. Set Secondary to None. The extra verse must disappear; navigation falls back to an available verse and unavailable live projection stops.
- Repeatedly start a search-result projection and immediately press Escape. Test Escape with the main window key and with the projector key. Then project another verse immediately. Check that no delayed request reopens a stopped window or clears the new projection.
- Search `jesus` with Malayalam primary and English secondary. Check match labels and both texts. Select using Up/Down and project with Return/Space. Search `love`, load every page, and confirm later books remain accessible.
- Click a bookmark or history entry in Ref, Words, and Phrase modes. One click must load and select its verse and update projection to that same reference. Stop projection, then click the same saved item again; it must resume. Project another verse and click the still-selected saved item; it must restore that saved verse. Replaying saved items must not add history entries. Clear bookmarks, Undo, and Redo.
- Clear bookmarks, add a new bookmark, then Undo each action and Redo them. Confirm entries change in the expected order and persist after reopening. Check Command-C with a selected verse, a secondary-only verse, and loading/empty states.
- Use the native search field's recent-query menu in each mode and its cancel button. Typing must not submit a query; Return must submit once. Escape must stop projection while keeping the draft. Resize between wide and compact controls while editing and confirm the insertion point stays put; Command-L must refocus the field after using another control.
- Choose a different book, then click a chapter once. The first click must load and highlight that chapter and keep chapter keyboard focus. Repeat after switching books again and when returning to the already-selected chapter; its highlight must stay on after every repeated click.
- Choose a different book, press Tab, then an arrow key without clicking a chapter. The first arrow must select and load chapter 1; subsequent arrows follow the grid's spatial layout. Return/Space must also open chapter 1 from an unselected grid. Tab alone must not navigate or project. Check Shift-Tab back to books and both Tab directions out of the verse table.
- Use Tab/Shift-Tab and VoiceOver to reach search, mode controls, translation pickers, chapter buttons, saved-reference rows, search results, Load more, Blank, Preview, and Stop. Check action labels and focus after submitting a search. Enable Reduce Motion and submit an invalid query.
- Import a valid translation while the verse view remains mounted. Confirm both pickers update immediately. Replace it and confirm new text loads. Reject a malformed replacement and confirm the previous translation remains usable. Remove it, then restore it from Trash. Open a `.bible` file from Finder to exercise the registered file handler.
- Remove a selected imported translation, then re-import the same filename. The tab must use a fallback while it is missing and restore the preferred translation afterward, preserving the live reference and blanking. Repeat after explicitly choosing the fallback: that new preference must remain selected. An empty catalog should show import instructions, disable pickers, and stop output from an open source tab; restoring a translation must allow browsing and clear the empty-catalog footer in every tab without automatically resuming projection. Repeat recovery after closing all passage tabs. If the source tab closed before the catalog emptied, output stays frozen; Stop and Escape must still stop it while Space has no selected row to act on.
- Open Settings in light and dark appearance. Check the native Display and Bible Library toolbar tabs, slider/readout alignment, and keyboard/VoiceOver access. Drag each slider and confirm the displayed value follows smoothly while live output updates on release; keyboard adjustments should apply immediately. Close and reopen Settings to check persistence. In Bible Library, select included and imported rows, cancel a removal, and import multiple files from the native panel. Check the empty catalog state and spacing between translation labels, pickers, and the verse table at compact and normal workspace widths.
- Start a replacement import in Settings and switch to Display before validation finishes. Its decision must still appear. Close Settings during validation or an unresolved decision, then open another Bible from Finder. The existing translation must be kept and later imports must continue, including after reopening Settings.
- After a projection failure, dismiss its footer message from another passage tab; it must disappear everywhere. Explicit Stop also clears it. If changing translations automatically stops unavailable output, its explanation must remain until dismissed or another projection is requested.
- Select an explicit projector display, disconnect it, and reconnect it. Repeat with three displays and fullscreen Spaces. Confirm the preference remains selected, fallback is visible, reconnect returns to the chosen display, and rapid notifications do not churn window geometry.
- Check Esther 8:9 and long Malayalam text at 1920×1080, 1024×768, and 640×480, with stacked and side-by-side output, large padding, and RTL/LTR mixes. Preview uses the selected screen's proportions. Verify no verse truncation and judge readability at the actual viewing distance. Test Blank on black and transparent backgrounds.

## Automated fixtures

Regenerate the offscreen layout fixtures with `scripts/render-projector-review.sh`. PNGs are written to `build/review/rendered`; the renderer uses process-local volatile defaults and does not change saved app preferences.

Run `scripts/render-navigation-review.sh` for the AppKit workspace fixtures in `build/review/navigation`. The script launches a fixture app through LaunchServices with a repository translation catalog. It runs a real `NSApplication` event loop and dispatches synthetic events through a key window to check book/chapter and saved-reference activation, spatial grid navigation, toolbar commands, passage tabs, and adaptive bilingual layouts. Projector window creation is suppressed. Native macOS glass is not fully captured by offscreen view caching, so appearance requires an onscreen check.

Use `scripts/render-navigation-review.sh --settings-only --onscreen` for native Settings screenshots in light/dark appearance, slider tracking and keyboard persistence, library selection/removal cancellation, empty catalogs, and import-sheet lifecycle checks. Use `scripts/render-navigation-review.sh --inspect-settings --onscreen` for manual inspection in the isolated Settings fixture; closing its window ends the run.

Use `scripts/render-navigation-review.sh --history-reveal-only` for the focused Psalm 117:2 → History Esther 8:9 checks and screenshots at normal and compact sizes, with bilingual text and Secondary set to None.

Use `scripts/render-navigation-review.sh --passage-tabs-only` for passage retention, independent translation choices, source ownership, and Live/Blanked headings. Add `--onscreen` when macOS drops key-window status from offscreen fixture windows. This shows the fixture workspaces while keeping projector windows suppressed; it still uses synthetic window events.

Passage-tab regression coverage also lives in `Tests/PassageProjectionTests.swift` and the native event harness, including noncooperative canceled database work. Tab dragging/detaching, physical input, VoiceOver, and real projector display behavior still require the interactive checks above.

## Self-update release checks

Check the update menu, automatic-check toggle, and shared toolbar reminder in
multiple passage tabs. A scheduled update must preserve the search editor and
live projection without opening a dialog. Check offline/error and up-to-date
responses. With a disposable signed/notarized installation, verify installing a
newer release, rejecting a corrupted archive, relaunching, and retaining Bible
imports, bookmarks, history, and settings. See [self-updates](self-updates.md).
